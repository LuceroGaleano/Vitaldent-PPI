# 🦷🧑‍⚕️ Vitaldent 🧑‍⚕️🦷

Este proyecto implementa un sistema web enfocado en un consultorio odontológico, que permita digitalizar los procesos administrativos y clínicos. Busca la reducción de errores humanos, mejorar la organización y aumentar la productividad del consultorio.

## 🚀 Tecnologías utilizadas

- **Para el backend**:
  - **Java**: Lenguaje principal utilizado para el desarrollo del backend.
  - **Spring Boot**: Framework para el desarrollo de la aplicación.
  - **Programación Orientada a Objetos (POO)**: Paradigma utilizado para la estructura de los objetos.
  - **Arquitectura hexagonal**: Enfoque arquitectónico para el backend, dividiendo el proyecto por tres capas:
    - `domain`: Lógica de negocio y reglas principales.
    - `application`: Casos de uso, servicios de la aplicación y controladores.
    - `infrastructure`: Persistencia, configuraciones y seguridad.

- **Para el frontend**:
  - **React**: Librería principal para la construcción de la interfaz de usuario basada en componentes.
  - **JavaScript**: Lenguaje de programación para la lógica interactiva del cliente.
  - **HTML5 & CSS3**: Estructura semántica y diseño visual de las vistas.
  - **Bootstrap 5**: Framework CSS utilizado para el diseño responsivo y componentes estilizados.

## 🖥️ Prerrequisitos

Antes de comenzar con la instalación, asegúrate de tener instalado:
- **Node.js**: Versión 18.x o superior (incluye npm).
- **Gestor de Base de datos**: MySQL.
- **Git**: Para la clonación del repositorio y el control de versiones.
- **IDE**: Tener instalado algún IDE (como recomendación: VS Code, IntelliJ IDEA o NetBeans).

## ⚙️ Instalación y Configuración

1. **Clonar el repositorio**.
2. **Abrir el proyecto** en tu IDE de preferencia.
3. **Ejecutar el backend**:
   - Configurar las variables de entorno o la conexión a la base de datos en el archivo de propiedades.
   - Compilar y ejecutar la aplicación Spring Boot.
4. **Ejecutar el frontend**:
   - Abrir en la terminal la carpeta correspondiente al frontend.
   - Instalar las dependencias del proyecto ejecutando `npm install`.
   - Iniciar el servidor ejecutando `npm run dev`.
